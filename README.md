# HyperOS Offline Ledger

一款面向个人使用的 Android 离线记账应用，优先适配小米 HyperOS，并尽量兼容其他 Android 设备。

> 当前仓库处于规划阶段，尚无可用 APK。实现范围和安全边界以文档为准。

## 计划能力

- 识别微信、支付宝的支出、收入与退款。
- HyperOS 三指截屏后，本地识别支付成功页面并提取金额、时间等字段。
- 仅对满足页面特征与新鲜度要求的高置信度结果自动入账。
- 固定月预算、每日参考预算、当日结余/超支提醒和标签统计。
- 导入微信、支付宝官方账单进行补漏、去重与最终对账。
- 导出 CSV 与 XLSX 月报。
- 完全离线运行，不申请网络权限，不上传截图、账单或日志。

## 重要风险

- 微信、支付宝和 HyperOS 更新可能改变通知、SystemUI 截图行为及支付页面结构，导致漏记或误判。
- 自动发现截图需要 Android 的完整照片读取权限。应用实现只处理刚生成的截图候选，但该系统权限技术上允许读取更多图片。
- OCR 不能单独证明交易成功。聊天截图、账单分享图、历史详情页和包含“支付成功”文字的其他图片必须作为负样本处理。
- 应用不会绕过 `FLAG_SECURE`，不会录屏，不会自动点击付款按钮，也不会读取支付密码。
- 删除系统截图必须再次经过 Android/HyperOS 的系统确认；应用不能静默删除非自身创建的图片。
- 导出的 CSV/XLSX 是明文文件，可能包含财务信息。用户需自行选择安全的保存位置。
- GitHub Issue 默认公开。不要上传未经脱敏的付款截图、账单、二维码、订单号、姓名、头像、商户信息或诊断数据。
- Root、恶意输入法、系统失陷或用户主动授予其他恶意应用高权限不在本项目的保护范围内。

官方账单导入用于提高一致性，但不等同于银行清算凭证。涉及重要财务判断时应以支付平台和银行记录为准。

## 隐私原则

- 不声明 `INTERNET` 权限，不接入账号、广告、遥测或云同步。
- 原始截图只在本机读取和处理，不复制进应用数据库。
- 默认日志不保存完整 OCR 文本、通知正文、金额、商户或原始图片。
- 诊断数据必须由用户主动导出，并在提交 Issue 前进行检查和脱敏。
- 测试夹具只使用合成数据或彻底脱敏的样本。

## 问题反馈

提交 Issue 前请阅读模板中的隐私提示，并提供：

- 手机型号、Android/HyperOS 版本。
- 应用、微信或支付宝版本。
- 可重复的操作步骤和实际结果。
- 应用主动导出的脱敏诊断信息。

如果问题必须依赖图片复现，请优先构造不含真实个人和交易信息的样本。不要在公开 Issue 中提交无法充分脱敏的原图。
