# Android 云端智能记账

一款面向个人使用、支持通用 Android API 26+ 的智能记账应用。小米/HyperOS 设备作为兼容性测试设备之一，不限制产品支持范围。

> 当前版本为 `v0.4.1`。截图发现与 VLM 处理使用持久队列，支持断网熔断与退避重试、进程恢复、包名黑白名单、可选原图副本、待删除队列、可缺字段账目、账本编辑以及 CSV/XLSX 导出。本补丁修复图库截图和疑似账目无法删除的问题。

## 支持范围

- Android API 26 及以上。
- Android 13+ 使用 `READ_MEDIA_IMAGES`；Android 12 及以下使用对应的存储读取权限。
- 具体设备的权限弹窗、MediaStore 元数据和删除确认可能略有差异，应用通过标准 API 兼容处理。
- AOSP、主流 Android 设备和 HyperOS 设备均纳入测试矩阵。

## 当前能力

- 通过 MediaStore 发现最近截图，逐张原位读取照片。
- 用户同意后，将当前照片发送到自己配置的 OpenAI 兼容 VLM 服务；支持 Responses API 与 Chat Completions 两种显式协议。
- 根据严格的 `ledger.v1` JSON 识别微信、支付宝等支付页面的支出、收入和退款。
- 满足置信度、成功状态、金额唯一性和新鲜度条件时自动入账，否则进入待确认列表。
- 高置信度入账后提供修改标签、保留截图或请求系统删除截图的操作。
- 固定月预算、每日参考预算、当日盈余/超支、跨月预算池和独立存款台账。
- 导入微信、支付宝官方账单进行格式校验、补漏与去重。
- 导出 CSV 与 XLSX 月报。

## 云端与隐私边界

- 云端识别默认关闭，启用前明确提示照片会离开设备并发送至第三方 VLM 服务。
- 设置页只提供接口协议、`Base URL`、`API Key`、模型和超时等表单项，不允许编辑原始 JSON。
- API Key 使用 Android Keystore 加密保存，界面掩码显示，绝不写入日志、诊断包或版本库。
- 每次请求只发送当前照片和固定提示词；应用不上传账本数据库、完整日志或其他照片。
- 服务端应承诺在处理完成后立即删除原图和临时文件。应用默认不复制原图；用户可明确开启“应用内保留原图副本”，副本保存在应用私有目录。客户端无法验证任意第三方服务的实际留存行为。
- 网络不可用、Key 无效、服务限流或模型返回无效 JSON 时，不会生成伪造账目；当前界面会显示失败原因，合法但不满足自动入账条件的结果进入人工确认。
- 账本管理、预算、预算池、存款台账、官方账单导入和 CSV/XLSX 导出完全在本机运行，不依赖网络；云端 VLM 识别仍需要联网。

## 使用提示

1. 使用 JDK 17 和 Android SDK 37，在仓库根目录运行 `./gradlew :app:assembleDebug`（Windows PowerShell 使用 `.\gradlew.bat :app:assembleDebug`）。调试 APK 生成在 `app/build/outputs/apk/debug/app-debug.apk`；当前版本仅用于开发验证，请勿把真实密钥打包进源码或构建脚本。
2. 首次打开应用时，先在“云端识别设置”选择接口协议，并填写服务商提供的 `Base URL`、`API Key` 和 `Model`，设置超时后点击“测试连接”。`Base URL` 只填写 HTTPS 服务根地址或 `/v1` API 根地址，不要填写完整的 `/responses`、`/chat/completions` 路径、查询参数或密钥。连接测试不上传照片，但供应商仍可能对探测请求计费。
3. 使用硅基流动时，选择 `Chat Completions`，填写 `https://api.siliconflow.cn` 和视觉模型名，例如 `Qwen/Qwen3.8-27B`。连接测试使用不含图片的普通文本探针；正式识别把完整 Prompt 与当前图片放在同一条多模态消息中，不发送工具调用、JSON Mode 参数，也不会为了格式修复再次上传同一图片。
4. 确认服务商的图片留存、模型训练、跨境传输和计费政策，再打开“启用云端识别”。应用不会在开关关闭时上传照片。
5. 点击“授予权限”允许应用发现近期截图。Android 14 及以上若只授予部分照片访问权，自动发现可能不可用；此时使用“选择照片”通过系统文件选择器明确选择要处理的图片，该路径不要求授予整个图库的读取权限。
6. 如需应用未打开时继续处理，可主动开启“后台自动处理”。应用使用带常驻通知的前台截图观察服务实时发现变化，以无网络约束的 WorkManager 每 15 分钟兜底发现，再由带联网约束的独立任务消费持久队列。系统强制停止应用后仍需用户重新打开；省电和厂商策略可能造成延迟。
7. 点击“识别最近截图”后，应用会逐张读取近期截图并发送到配置的 VLM。网络错误或限流不会生成账目，请根据结果提示重试；无效 JSON 会进入不含模型猜测值的空白人工确认表单。合法但未达到自动入账条件的结果也会显示字段表单，必须核对或修正平台、方向、金额、币种和交易时间后才能确认录入。
8. HyperOS 文件名末尾的包名会被提取并应用“全部/白名单/黑名单”规则；白名单和黑名单通过带名称、图标与包名的已安装应用选择器配置，默认空黑名单允许所有截图来源。VLM 区分非交易图片、即时成功页、单笔已完成订单详情和列表页面；只有证据完整的成功交易自动入账，其余进入待确认或忽略。
9. 高置信度账目成功保存后，可将原截图加入待删除队列。Android 11 及以上可在设置页一次性发起系统批量删除确认；Android 10 及以下按系统能力逐张处理。开启原图副本后，应用会先复制到私有目录再请求删除图库原图。
10. API Key 只在本机 Keystore 保护下保存，输入框会掩码显示；可在设置中替换或清除，清除后云端识别会同时关闭。不要把 Key、原图、完整响应或账单上传到公开 Issue；需要反馈时只提交脱敏诊断信息。
11. 在“识别”页点击“导入支付宝/微信账单”，选择官方导出的 CSV、XLSX，或包含上述文件的 ZIP。应用会在本机校验平台表头、交易号、时间、金额、收支方向和完成状态，先显示可导入/跳过/异常数量；只有点击“确认导入”后才写入账本。失败、待支付、不计收支和格式异常行不会入账，重复交易会按交易号及现有指纹规则跳过。加密 ZIP 需要先在系统文件应用中解压。

## 账本与每日预算

- 应用启动后默认进入“账本”页；“识别”页负责截图处理，“设置”页负责 VLM 与后台任务配置。
- 月预算只使用 CNY，以分为单位存储，并按当月自然日数均摊。无法整除的分单位依次补到当月前几天，因此所有每日基础预算之和严格等于月预算。
- 当日净支出等于 CNY 支出减退款；收入单独展示，不改变每日预算结算。月度预算占用等于当月净支出减收入，因此本月收入会抵扣月预算。非 CNY 流水显示在账本中，但不参与预算计算。
- 今日只提供实时预览。次日开始，过去日期的正盈余可以转入跨月预算池，或记入独立存款台账。
- 预算池由用户手动拨入今天或尚未结算的过去日期；不能向未来日期预拨，拨款也不能超过池余额。超支日期会建议恰好补足超支的金额。
- 已结算日期后来新增交易，或当月预算发生修改时，该日会标记为“需要重新结算”。重新结算保留旧版本并追加冲正记录；若旧盈余已经被使用，预算池会显示调整欠额，欠额清零前不能继续拨款。
- 账本支持手工新增、修改和删除交易，核心字段允许暂缺；缺少时间的账目按创建日期展示但不伪造交易时间。存款台账暂不支持取出金额。
- 官方账单导入不会把原文件复制到应用目录，也不会上传云端；导入记录使用 `STATEMENT_VERIFIED` 时间来源，并继续沿用现有账本去重规则。

## 重要风险

- 第三方 VLM 服务可能记录、处理或短暂缓存图片；使用前应确认供应商的留存、训练和跨境传输政策。
- API Key 虽使用 Keystore 保存，仍可能因设备失陷、调试环境或用户主动泄露而暴露；APK 混淆不能保护长期密钥。
- VLM 可能误识别金额、时间、商户或支付状态。聊天截图、账单列表、历史详情、分享海报和图片预览必须作为负样本处理。
- 断网、超时、限流、服务端错误或返回格式变化会导致识别延迟或进入待确认，不应自动猜测字段。
- Android 13+ 的照片读取授权会影响自动发现；Android 14+ 还可能只授予部分照片访问权。未获完整权限时可使用系统文件选择器逐张或多张选择。
- 删除系统照片按版本走用户可见流程：API 30+ 显示系统删除确认，API 29 在需要时显示可恢复权限确认，API 26-28 仅在用户点击并授予写权限后删除。应用不能静默删除非自身创建的照片。
- 导出的 CSV/XLSX 是明文文件，可能包含财务信息。用户需自行选择安全的保存位置。
- Root、恶意输入法、系统失陷或用户主动授予其他恶意应用高权限不在项目保护范围内。

官方账单导入用于提高一致性，但不等同于银行清算凭证。涉及重要财务判断时应以支付平台和银行记录为准。

## 问题反馈

提交 Issue 前请提供：

- 设备型号、Android/HyperOS 版本和 API 级别；
- 应用、微信或支付宝版本；
- VLM 服务类型和脱敏后的错误类别（不要提交 API Key 或完整 URL 凭据）；
- 可重复的操作步骤、实际结果和应用主动导出的脱敏诊断信息。

不要在公开 Issue 中提交含真实姓名、头像、金额、商户、订单号、二维码、账单或原始付款截图。需要图片复现时，优先构造合成或彻底脱敏样本。
